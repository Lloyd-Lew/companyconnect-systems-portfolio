CompanyConnect’s public GitHub evidence is intentionally layered. Prospects should start with the evidence appropriate to their question, rather than treating a client-safe reference repository as a customer system or treating a sales overview as technical due diligence.

| How is public work kept client-safe? | [Public Portfolio Policy](public-portfolio-policy.md) and [Security Policy](../SECURITY.md) | Publication gate, confidential-data boundary, and private reporting route. |

## Public proof boundary

The repositories use synthetic data, deterministic adapters, and explicit production limitations. They demonstrate architecture, engineering practices, and service fit. They do not disclose client systems or certify a real environment. For scoped technical due diligence, use the [Engineering Hub trust route](https://lloyd-lew.github.io/companyconnect-engineering-hub/trust.html) as a starting point, then move to an appropriate discovery process.
