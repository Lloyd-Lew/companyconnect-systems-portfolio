# Security and Confidentiality

CompanyConnect.Tech takes the confidentiality of client systems seriously. This public portfolio is intentionally designed **not** to contain customer records, credentials, API keys, webhook URLs, live workflow configurations, access links, or confidential implementation detail.

## Report a security concern

If you believe you have found an exposed credential, sensitive client information, an unintended public file, or another security concern related to this repository, do not open a public issue. Email [letsconnect@companyconnect.tech](mailto:letsconnect@companyconnect.tech?subject=Security%20concern%20-%20CompanyConnect%20portfolio) with:

| Include | Why it helps |
| --- | --- |
| A concise description of the concern | Helps assess impact quickly |
| The affected repository path or public URL | Identifies the relevant content without sharing it widely |
| The steps needed to reproduce the observation | Allows safe confirmation |
| Any recommended remediation | Provides useful context for triage |

Please avoid sending credentials, client data, or other sensitive material by email unless it is essential to explain the issue. We will acknowledge a credible report, assess the exposure, remove or restrict access where appropriate, and rotate affected values if required.

## Responsible use of this portfolio

The workflows and delivery patterns presented here are educational examples of CompanyConnect.Tech capability. They are not customer implementations, production credentials, or reusable client configurations. Do not rely on these summaries as operational, legal, security, or compliance advice for your own environment.
