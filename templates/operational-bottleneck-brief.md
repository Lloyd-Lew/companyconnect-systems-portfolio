# Operational Bottleneck Brief

> Use this short brief to prepare for a CompanyConnect.Tech strategy call or AI Business Audit. The goal is not a perfect specification. The goal is to identify the operational friction with the clearest commercial value.

## 1. The situation

| Prompt | Your notes |
| --- | --- |
| What business outcome needs to improve? | |
| Which team, role, or customer is affected? | |
| What happens today, from the first trigger to the final outcome? | |
| Where does the process slow down, break, duplicate work, or lose information? | |

## 2. The operational cost

| Prompt | Your notes |
| --- | --- |
| What is the practical consequence today: lost revenue, delayed response, rework, error, lack of visibility, or staff time? | |
| How often does the problem happen? | |
| Which measure would show that the situation has improved? | |
| What would change if the process worked reliably? | |

## 3. The current system landscape

| Prompt | Your notes |
| --- | --- |
| Which CRM, finance, communication, project, form, spreadsheet, or data tools are involved? | |
| Where is the source of truth today? | |
| Who owns the process and who needs visibility? | |
| Are there approval, privacy, access, or compliance constraints? | |

## 4. The right next step

Use the guide below after completing the brief.
