# Contribution and Correction Guidance

This repository is a curated commercial portfolio, not an open-source software project. It does not accept client configurations, raw workflow exports, implementation files, credentials, or work product through public pull requests.

## Suggesting a correction

If you notice a factual error, inaccessible resource, broken public link, or unclear explanation, email [letsconnect@companyconnect.tech](mailto:letsconnect@companyconnect.tech?subject=Portfolio%20correction%20or%20suggestion). Include the relevant public page or repository path and a concise explanation of the proposed correction.

## Before suggesting a public asset

Any future portfolio asset must be accurate, useful to a prospective client, and free from client-identifying information, private configuration, credentials, access routes, or unverified claims. Read the [Public Portfolio Policy](docs/public-portfolio-policy.md) before submitting a suggestion.

## Security concerns

Do not use a public request for suspected sensitive information or access exposure. Follow the private reporting route in the [Security Policy](SECURITY.md).
